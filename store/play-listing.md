## Full description (4000 characters max)

Photo Finder is a download fixer and file renamer for Android. It helps when Google Photos saves a download as a file with no extension, the wrong extension, or a junk filename—and when batch download is awkward.

**What Photo Finder does**

1. **Scan a folder you choose**  
   Pick a folder of files already on your device (for example where Google Photos put downloads). Photo Finder looks at each file’s content (magic bytes and, when available, EXIF) to tell images and videos apart. It does not search your whole photo library by picture content.

2. **Fix names after a preview**  
   For files that need help, you get a review list before anything is written. Photo Finder can rename in place or copy fixed files into another folder you pick. When EXIF has a capture date, it can suggest a sensible dated name; otherwise it keeps the existing basename and mainly fixes the extension. It finds a photo that downloaded without a proper name or extension—it does not pretend to recover Google’s original server filename for files that were already saved wrong.

3. **Share target from Google Photos**  
   Share images or videos from Google Photos to Photo Finder. The app reads the display name and MIME type, adds an extension from the type when the name has none, and saves the bytes into a save folder you choose.

**What Photo Finder is not**

- Not a photo editor—no filters, crops, or adjustments.  
- Not a library-wide visual search tool.  
- Cannot restore the original Google server filename for a file that was already downloaded with a bad or missing name.

**Keywords people search for:** photo finder, file, download, rename, renamer, download fixer.

Plain tool for fixing downloads—not affiliated with or endorsed by Google.
